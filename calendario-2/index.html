Calendario

7 julio, 2016


Sólo se necesita una funda de CD y este .pdf para imprimir. 1. Funda de CD Caso 2. Abre la Funda y retira la pieza de plástico que aguanta el CD 3. Entonces, gira la parte delantera y vuelve a conectar las piezas en el lugar previsto. No se puede cerrar! 4. Pinta las hojas impresas y cortalas al fomat marcado.
Terminado es el calendario, perfecto para el escritorio. Creo que es una gran idea para un regalo de Navidad, pero en el verano los niños tienen mucho más tiempo :-).
