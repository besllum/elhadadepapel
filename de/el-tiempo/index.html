El tiempo / The weather / Das Wetter

3. Februar 2012

Hemos perforado un cartón y henebrado un hilo siempre desde el centro. Así puedes tejer un sol, una flor …

The weather We pricked some wholes into a cardboard and then we thread the yarn always passing over the same middle point. Now you can weave a sun, a flower … Das Wetter Wir haben ein paar Löcher in einen Karton gestochen und dann einen Faden eingefädelt, so dass er immer über einen gemeinsamen Mittelpunkt liegt. Jetzt kannst Du alle möglichen Formen weben eine Sonne, eine Blume...
