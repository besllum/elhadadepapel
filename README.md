# El Hada de Papel

Versión estática (HTML) del blog **elhadadepapel.com** (2010–2018), generada a partir de la copia de WordPress de julio de 2018 (con la página de contacto actualizada de la copia de 2025).

- Español en la raíz, inglés en `/en/` y alemán en `/de/` (botón de idioma arriba a la derecha).
- 956 entradas por idioma, páginas, categorías, etiquetas y buscador.
- Imágenes en `wp-content/uploads/` (solo las que usa la web).

## Publicar en GitHub Pages
1. Sube esta carpeta a un repositorio de GitHub (por ejemplo con GitHub Desktop).
2. En el repositorio: *Settings → Pages → Deploy from a branch → main / (root)*.

## Regenerar
El generador y los informes están fuera del repositorio, en `../_work/` (`build.py`).
