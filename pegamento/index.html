Truco: pegamento barato para papel

17 febrero, 2012

Estreno una etiqueta nueva: TRUCOS. Para tener un pegamento de papel barato solo hay que mezclar cola de empapelar con agua. Se puede usar con las manos o con pincel y, en un bote cerrado, aguanta muchísimo tiempo.
